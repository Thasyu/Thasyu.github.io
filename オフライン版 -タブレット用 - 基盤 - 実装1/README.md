# WBT学習サイト

オフライン版タブレット用の学習システムです。

## 概要

このシステムは、iPad Pro（13インチ）向けに最適化された学習サイトです。

## 提供コンテンツ

- Oracle認定試験対策（1Z0-085, 1Z0-818）
- LPIC試験対策（LPIC-010-160）
- Linux試験対策（LinuC101-10.0）
- HTML5レベル1試験対策
- DX試験対策

## 技術スタック

- HTML5
- CSS3
- JavaScript
- jQuery 1.7.2

## 使用方法

`index.html`をブラウザで開いてください。

## デプロイ

このサイトはRenderを使用して静的サイトとしてデプロイされています。
